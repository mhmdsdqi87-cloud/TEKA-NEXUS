## 🌍 Qu'est-ce que TEKA NEXUS ?

TEKA NEXUS est né d'une seule question : **pourquoi apprendre à coder devrait-il être difficile** ?

C'est un écosystème complet qui fusionne **le réseautage, la création et l'apprentissage** en une
expérience unique, installable et parfaitement fluide : pas un site de cours avec un forum greffé
par-dessus, mais une **arène sociale** pour la prochaine génération de développeurs — pensée d'abord
en persan, ouverte sur le monde entier.

## 🎓 TEKA Academy — 300 leçons, zéro configuration

Quatre parcours, chacun conçu autour de **la pratique**, pas du visionnage :

| Parcours | Leçons | Moteur |
|---|:---:|---|
| 🐍 **Python** | 76 | **Interpréteur pylite** sur mesure — un sous-ensemble de Python exécuté entièrement dans le navigateur |
| 🌐 **HTML** | 73 | Aperçu en direct + **assertions DOM** |
| 🎨 **CSS** | 81 | Aperçu en direct + **correction par styles calculés** sur le DOM rendu |
| ⚡ **JavaScript** | 70 | Runtime iframe sandboxé avec **tests déterministes** |

**300 leçons au total** — chacune bilingue, compacte, pratique. Pédagogie :
**2 étapes de théorie → quiz → défi corrigé automatiquement** (code de départ, solution,
3 indices progressifs).

S'y ajoute le **Portail d'apprentissage** : parcours d'apprentissage, Bug Detective, Encyclopédie
des erreurs, Predict-the-Output, glossaire bilingue, favoris, série quotidienne, 12 succès, un
explorateur `Ctrl+K` avec recherche plein texte, et un **Tuteur IA socratique** (LLM côté serveur —
les clés ne touchent jamais le client).

### 🏅 Licence officielle TEKA
Un **examen final surveillé** (15 minutes, corrigé côté serveur, 3 tentatives maximum, anti-triche
côté serveur) → un certificat vérifiable avec un identifiant unique par parcours.

## 🏆 TEKA Arena — la couche de jeu

Chaque module vit **directement dans la barre de navigation principale** — aucune fenêtre, aucun
« metafloor », chaque jeu est une expérience plein écran de premier plan :

- 🟢 **Mode Matrix** — superposition plein écran de code tombant (`Ctrl+Shift+M`)
- 🌌 **Bandeau TEKA NIGHTS** — compte à rebours en direct vers le prochain événement mensuel
- 🔗 **Liens profonds** — `teka learn css` ouvre l'académie directement au cours CSS
- ⌨️ **Terminal** — un vrai shell : `teka boss`, `matrix on`, `neofetch`… et un secret

## ✨ Tour d'horizon des fonctionnalités

<details open>
<summary><b>Social et collaboration</b></summary>

- Publications, likes, commentaires, repartages, favoris, recherche par hashtag
- Suivre / bloquer / mettre en sourdine, notifications granulaires (dans l'app + compteurs de badge)
- Messages privés avec état de lecture
- Espaces de travail de projet : tâches kanban, jalons, mises à jour, liens de fichiers
- **Chat d'équipe** en temps réel via un mini-service socket.io dédié (présence, saisie en cours, réactions, historique)
- Demandes de collaboration avec négociation de rôle (contributor / viewer)
- Intégration GitHub : panneaux de dépôt, contributeurs de la communauté
- Console fondateur : statistiques de communauté en direct + gestion des membres (accès par rôle)

</details>

<details>
<summary><b>Authentification et sécurité</b></summary>

- E-mail / mot de passe avec hachage **scrypt** (sel unique par utilisateur, `timingSafeEqual`)
- Cookies de session httpOnly, sessions de 30 jours côté serveur
- Les 60+ endpoints REST, tous validés avec zod ; autorisation vérifiée à chaque requête côté serveur
- Anti-triche pour examens et speedruns, appliqué **côté serveur**
- IA et TTS relayés uniquement via les routes serveur — aucune clé n'atteint jamais le navigateur

</details>

<details>
<summary><b>Expérience et plateforme</b></summary>

- **Séquence de démarrage cinématique** : canvas en réseau de neurones, anneaux orbitaux, journal de démarrage type terminal (≈8 s, respecte `prefers-reduced-motion`)
- Langage de design **glassmorphism** : flou en couches, accents néon, physique à ressort (framer-motion)
- **PWA** : installable, icônes aux couleurs de la marque, service worker sécurisé (production uniquement)
- Support **RTL** complet pour le persan et l'arabe (composants sensibles à la direction)
- Heatmap à la GitHub, séries, compteurs de statistiques animés, système de toasts, skeletons partout

</details>

## 🏗️ Architecture

```text
┌────────────────────────────────────────────────────────────────────┐
│                        Browser (PWA client)                        │
│  Next.js 16 App Router SPA — zustand router, framer-motion, 7 i18n │
│  TEKA Arena · pylite interpreter · sandboxed iframes               │
└──────────────────────────────┬─────────────────────────────────────┘
                               │  REST (zod-validated, session cookie)
┌──────────────────────────────▼─────────────────────────────────────┐
│                     Next.js API routes (60+)                       │
│  auth · social · projects · academy · exam · arena (12 modules) ·  │
│  universe · dna · tts · server-side grading · anti-cheat · LLM proxy│
└───────────────┬────────────────────────────────┬───────────────────┘
                │ Prisma ORM                     │ socket.io client
┌───────────────▼────────────────┐  ┌────────────▼───────────────────┐
│   PostgreSQL (Supabase)        │  │  mini-services/chat-service    │
│   30+ models: User, Post,      │  │  dedicated Bun process, own    │
│   Project, Task, Session,      │  │  port & package.json — real-   │
│   License, War*, Pet*, Card*,  │  │  time team chat (rooms, pres-  │
│   Speedrun*, Activity …        │  │  ence, typing, reactions)      │
└────────────────────────────────┘  └────────────────────────────────┘
```

### Stack technique

<div align="center">
  <a href="https://skillicons.dev">
    <img src="https://skillicons.dev/icons?i=ts,nextjs,tailwind,prisma,postgres,bun,vercel,github&theme=dark" alt="Icônes du stack technique">
  </a>
</div>

| Couche | Choix | Pourquoi |
|---|---|---|
| Framework | **Next.js 16** (App Router, sortie standalone) | Coquille SPA prête pour RSC, une seule cible de déploiement |
| Langage | **TypeScript 5**, strict | Sécurité des types de bout en bout, dictionnaires typés pour 7 langues |
| Style | **Tailwind CSS 4** + shadcn/ui + Lucide | Système de design glass/neon cohérent |
| Animation | framer-motion | Physique à ressort, transitions de page, effets d'arène |
| BDD | **Prisma ORM** → PostgreSQL (Supabase prod / SQLite dev) | Schéma typé, 30+ modèles, zéro dérive SQL |
| Temps réel | Mini-service socket.io (Bun) | Scaling isolé + domaine de crash dédié pour le chat |
| IA | Tuteur LLM côté serveur + narration TTS | Aide personnalisée, leçons audio |
| Hébergement | Vercel (frontend+API) · Supabase (DB) | CI/CD au push, zéro ops |

## 🚀 Démarrage rapide

```bash
# 1. install
bun install                        # or: npm / pnpm / yarn

# 2. environment
cp .env.example .env               # SQLite works out of the box for local dev
#   DATABASE_URL="file:./db/custom.db"          ← dev default
#   For Supabase Postgres see docs/SUPABASE.md

# 3. schema
bun run db:push

# 4. run
bun run dev                        # http://localhost:3000

# 4b. real-time chat service (optional, separate terminal)
cd mini-services/chat-service && bun run dev
```

> 📦 **Production** : Vercel + Supabase — guide complet dans [`docs/DEPLOY.md`](docs/DEPLOY.md)
> (y compris le packaging AAB Android via TWA pour les stores d'applications).
