поколения разработчиков: персидский — прежде всего, двери открыты всему миру.

## 🎓 Академия TEKA — 300 уроков, ноль настройки

Четыре направления, и каждое выстроено вокруг **действия**, а не созерцания:

| Направление | Уроков | Движок |
|---|:---:|---|
| 🐍 **Python** | 76 | Собственный **интерпретатор pylite** — подмножество Python, целиком исполняемое в браузере |
| 🌐 **HTML** | 73 | Живой предпросмотр + **DOM-ассерты** |
| 🎨 **CSS** | 81 | Живой предпросмотр + **оценка по computed-style** отрисованного DOM |
| ⚡ **JavaScript** | 70 | Изолированный runtime в iframe с **детерминированными тестами** |

**Всего 300 уроков** — и каждый двуязычный, компактный, практичный. Педагогика:
**2 шага теории → тест → задание с автопроверкой** (стартовый код, решение,
3 подсказки с нарастающей сложностью).

Плюс **Учебный портал**: траектории обучения, Bug Detective, энциклопедия
ошибок, Predict-the-Output, двуязычный глоссарий, закладки, серии дней,
12 достижений, обозреватель `Ctrl+K` с полнотекстовым поиском и
**Сократический ИИ-наставник** (LLM на стороне сервера — ключи никогда
не попадают в клиент).

### 🏅 Официальная лицензия TEKA
**Итоговый экзамен с прокторингом** (15 минут, оценка на сервере, максимум
3 попытки, серверный анти-чит) → верифицируемый сертификат с уникальным ID
для каждого направления.

<details>
<summary><b>Аутентификация и безопасность</b></summary>

- Вход по e-mail и паролю с хешированием **scrypt** (индивидуальная соль на пользователя, `timingSafeEqual`)
- Сессионные cookie httpOnly, серверные сессии длительностью 30 дней
- Все 60+ REST-эндпоинтов валидируются через zod; авторизация проверяется на сервере для каждого запроса
- Анти-чит для экзаменов и спидранов работает **на стороне сервера**
- ИИ и TTS проксируются только через серверные маршруты — ни один ключ никогда не попадает в браузер

</details>

<details>
<summary><b>Пользовательский опыт и платформа</b></summary>

- **Кинематографичная загрузка**: канвас с нейросетью, орбитальные кольца, терминальный лог загрузки (≈8 с, учитывает `prefers-reduced-motion`)
- Дизайн-язык **глассморфизм**: многослойное размытие, неоновые акценты, пружинная физика (framer-motion)
- **PWA**: устанавливаемое приложение, фирменные иконки, безопасный service worker (только в production)
- Полная поддержка **RTL** для персидского и арабского (компоненты, учитывающие направление письма)
- Тепловая карта в стиле GitHub, серии дней, анимированные счётчики статистики, система всплывающих уведомлений (toast), скелетоны повсюду

</details>

```bash
cp .env.example .env               # SQLite works out of the box for local dev
#   DATABASE_URL="file:./db/custom.db"          ← dev default
#   For Supabase Postgres see docs/SUPABASE.md

# 3. schema
bun run db:push

# 4. run
bun run dev                        # http://localhost:3000

# 4b. real-time chat service (optional, separate terminal)
cd mini-services/chat-service && bun run dev
```

> 📦 **Продакшен**: Vercel + Supabase — полный регламент развёртывания в [`docs/DEPLOY.md`](docs/DEPLOY.md)
> (включая сборку Android AAB через TWA для магазинов приложений).
