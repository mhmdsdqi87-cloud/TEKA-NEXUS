## 🌍 تکا نکسوس چیست؟

تکا نکسوس با یک سؤال شروع شد: **چرا یادگیری برنامه‌نویسی باید سخت باشد؟**

یک اکوسیستم کامل که **شبکه‌سازی، ساختن و یادگیری** را در یک تجربه یکپارچه ترکیب می‌کند — نه یک سایت دوره با یک فروم اضافه، بلکه یک **آرنای اجتماعی** برای نسل بعدی توسعه‌دهنده‌های ایران و جهان:

| ستون | چی ارائه می‌دهد |
|---|---|
| 🧭 **کشف کن** | فید واقعی فناوری — پروژه‌ها، سازنده‌ها، اعتباری که با *عمل* کسب می‌شود نه با کلیک |
| 🤝 **بساز** | فضای کاری پروژه: کانبان، مایلستون، کامنت رشته‌ای، درخواست همکاری و **چت تیمی real-time** (socket.io) |
| 🎓 **یاد بگیر** | آکادمی رایگان برای همیشه: ۳۰۰ درس عملی، پایتون داخل مرورگر، پیش‌نمایش زنده HTML/CSS، چالش‌های خودتصحیح‌شونده |
| 🏆 **رقابت کن** | ۱۲ ماژول بازی در ناوبری اصلی — Boss Fight، درخت مهارت، Code Pet، کارت‌ها، جنگ سرخ و آبی و بیشتر |
| 🎮 **بازی کن** | اقتصاد XP، کارت‌های کلکسیونی، اسپیدران، TEKA Night ماهانه |

## 🎓 آکادمی تکا — ۳۰۰ درس، بدون هیچ راه‌اندازی

چهار مسیر، هرکدام مهندسی‌شده حول **عمل کردن**، نه تماشا کردن:

| مسیر | درس | موتور |
|---|---|---|
| 🐍 پایتون | ۷۶ | **مفسر pylite** — زیرمجموعه پایتون که کاملاً داخل مرورگر اجرا می‌شود |
| 🌐 HTML | ۷۳ | پیش‌نمایش زنده + اظهارات DOM |
| 🎨 CSS | ۸۱ | پیش‌نمایش زنده + تصحیح computed-style |
| ⚡ JavaScript | ۷۰ | ران‌تایم iframe ایزوله با تست‌های قطعی همزمان |

**در مجموع ۳۰۰ درس** — همه دوزبانه، فشرده و عملی. هر درس: ۲ گام تئوری → کوئیز → چالش خودتصحیح‌شونده (کد شروع، راه‌حل، ۳ راهنمای تدریجی).

به‌علاوه **پرتال یادگیری**: مسیرهای یادگیری، دانسته‌ی باگ، دانشنامه خطاها، واژه‌نامه دوزبانه، استریک روزانه، ۱۲ دستاورد، جستجوی کامل درس‌ها (Ctrl+K) و **مدرس هوش مصنوعی سقراطی** (کلیدها فقط سمت سرور).

### 🏅 مجوز رسمی تکا
امتحان پایانی **نظارت‌شده** (۱۵ دقیقه، تصحیح سمت سرور، حداکثر ۳ تلاش، ضدتقلب سرور) → گواهی قابل استعلام با شناسه یکتا برای هر مسیر.

## 🚀 راه‌اندازی سریع

```bash
# ۱. نصب
bun install                        # یا: npm / pnpm / yarn

# ۲. محیط
cp .env.example .env               # SQLite برای دِو لوکال آماده است

# ۳. اسکیما
bun run db:push

# ۴. اجرا
bun run dev                        # http://localhost:3000

# ۴ب. سرویس چت real-time (اختیاری، ترمینال جدا)
cd mini-services/chat-service && bun run dev
```
