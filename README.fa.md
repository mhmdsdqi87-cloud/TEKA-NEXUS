## 🎓 آکادمی TEKA — ۳۰۰ درس، بدون هیچ راه‌اندازی

چهار مسیر، هرکدام مهندسی‌شده دور **انجام دادن**، نه تماشا کردن:

| مسیر | درس‌ها | موتور |
|---|:---:|---|
| 🐍 **پایتون** | ۷۶ | **مفسر pylite** — زیرمجموعه‌ای از پایتون که کاملاً داخل مرورگر اجرا می‌شود |
| 🌐 **HTML** | ۷۳ | پیش‌نمایش زنده + **ادعاهای DOM** |
| 🎨 **CSS** | ۸۱ | پیش‌نمایش زنده + **تصحیح computed-style** روی DOM رندرشده |
| ⚡ **جاوااسکریپت** | ۷۰ | ران‌تایم iframe سندباکس‌شده با **تست‌های قطعی** |

**مجموعاً ۳۰۰ درس** — هر کدام دوزبانه، فشرده و عملی. پداگوژی:
**۲ گام تئوری → کوییز → چالش تصحیح‌شونده** (کد شروع، راه‌حل، ۳ راهنمای تدریجی).

به‌علاوه **پرتال یادگیری**: مسیرهای یادگیری، Bug Detective، دائرةالمعارف خطاها،
Predict-the-Output، واژه‌نامه‌ی دوزبانه، بوکمارک، استریک روزانه، ۱۲ دستاورد،
اکسپلورر `Ctrl+K` با جست‌وجوی تمام‌متن، و **معلم سقراطی AI** (LLM سمت سرور —
کلیدها هرگز به کلاینت نمی‌رسند).

### 🏅 لایسنس رسمی TEKA
**آزمون نهایی تحت نظارت** (۱۵ دقیقه، تصحیح سمت سرور، حداکثر ۳ تلاش، آنتی‌چیت
سمت سرور) → گواهی لایسنس قابل‌راستی‌آزمایی با شناسه‌ی یکتا برای هر مسیر.

## ✨ تور امکانات

<details open>
<summary><b>اجتماعی و همکاری</b></summary>

- پست، لایک، کامنت، رپست، بوکمارک، جست‌وجوی هشتگ
- فالو / بلاک / بی‌صدا، نوتیفیکیشن‌های ریزدانه (داخل‌اپ + شمارنده)
- دایرکت با وضعیت خوانده‌شده
- ورک‌اسپیس پروژه: تسک کانبانی، مایل‌استون، آپدیت، لینک فایل
- **چت تیمی ریل‌تایم** با مینی‌سرویس اختصاصی socket.io (presence، typing، ری‌اکشن، تاریخچه)
- درخواست همکاری با مذاکره‌ی نقش (contributor / viewer)
- یکپارچگی گیت‌هاب: پنل ریپو، مشارکت‌کنندگان جامعه
- کنسول بنیان‌گذار: آمار زنده‌ی جامعه + مدیریت اعضا (نقش‌محور)

</details>

<details>
<summary><b>احراز هویت و امنیت</b></summary>

- ایمیل/رمز با هش **scrypt** (نمک per-user، `timingSafeEqual`)
- کوکی سشن httpOnly، سشن‌های ۳۰ روزه سمت سرور
- تمام ۶۰+ اندپوینت REST با zod اعتبارسنجی؛ مجوزدهی هر درخواست سمت سرور
- آنتی‌چیت آزمون و اسپیدران **سمت سرور**
- AI و TTS فقط از مسیر روت‌های سرور — هیچ کلیدی هرگز به مرورگر نمی‌رسد

</details>

<details>
<summary><b>تجربه و پلتفرم</b></summary>

- **بوت‌سکوئنس سینمایی**: کانواس شبکه‌ی عصبی، حلقه‌های مداری، لاگ بوت ترمینال (≈۸s، رعایت `prefers-reduced-motion`)
- زبان طراحی **گلس‌مورفیسم**: بلور چندلایه، اکسنت‌های نئون، فیزیک فنری (framer-motion)
- **PWA**: قابل‌نصب، آیکون‌های برند، سرویس‌ورکر امن (فقط production)
- **RTL کامل** برای فارسی و عربی (کامپوننت‌های direction-aware)
- هیت‌مپ، استریک، شمارنده‌های آماری انیمیشنی، سیستم توست، اسکلتون همه‌جا

</details>

| ریل‌تایم | مینی‌سرویس socket.io (Bun) | اسکیل و کرش دامنه‌ی ایزوله برای چت |
| AI | معلم LLM سمت سرور + روایت TTS | کمک شخصی‌سازی‌شده، درس صوتی |
| میزبانی | Vercel (فرانت+API) · Supabase (DB) | CI/CD روی پوش، بدون عملیات |

## 🚀 شروع سریع

```bash
# ۱. نصب
bun install                        # یا: npm / pnpm / yarn

# ۲. محیط
cp .env.example .env               # SQLite برای دولوپ لوکال بدون تنظیمات کار می‌کند
#   DATABASE_URL="file:./db/custom.db"          ← پیش‌فرض دولوپ
#   برای Postgres ساپابایس ببین docs/SUPABASE.md

# ۳. اسکیما
bun run db:push

# ۴. اجرا
bun run dev                        # http://localhost:3000

# ۴ب. سرویس چت ریل‌تایم (اختیاری، ترمینال جدا)
cd mini-services/chat-service && bun run dev
```

> 📦 **پروداکشن**: Vercel + Supabase — ران‌بوک کامل در [`docs/DEPLOY.md`](docs/DEPLOY.md)
> (شامل پکیج‌بندی AAB اندروید از طریق TWA برای استورها).
