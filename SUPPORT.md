# Support

Thanks for using TEKA NEXUS — a social network for developers, a free
300-lesson coding academy and 12 coding-game modules, built by one person
and open to everyone.

## Where to ask

| You need... | Go to |
|---|---|
| A bug fix | [Open a bug report](https://github.com/mhmdsdqi87-cloud/TEKA-NEXUS/issues/new?template=bug_report.yml) |
| A new feature | [Open a feature request](https://github.com/mhmdsdqi87-cloud/TEKA-NEXUS/issues/new?template=feature_request.yml) |
| A question or an idea | [Open a Discussion](https://github.com/mhmdsdqi87-cloud/TEKA-NEXUS/discussions) |
| Setup and usage | [README](README.md) — Quick start — and the [docs/](docs) folder |
| Contributing code | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Security vulnerabilities | [SECURITY.md](SECURITY.md) — private disclosure, never a public issue |

## Before you open an issue

1. Search [existing issues](https://github.com/mhmdsdqi87-cloud/TEKA-NEXUS/issues) — yours may already be tracked.
2. Fill the template fully: reproduction steps, expected vs actual behavior, and your UI locale (the app ships in 7 languages).
3. For visual bugs, a screenshot or a short clip speeds everything up.

## Response expectations

TEKA NEXUS is maintained by one person — there are no SLAs. Real reports get
real attention, usually within a few days.
